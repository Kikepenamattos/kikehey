# Carpeta Teams

Esta carpeta contiene los archivos HTML generados automáticamente para cada team publicado.

## Formato de archivos

Los archivos siguen el formato: `team_{ID}_{nombre}.html`

Ejemplo:
- `team_1234567890123_equipo-desarrollo.html`

## Acceso

Cada archivo HTML puede ser accedido directamente mediante su URL:
```
teams/team_{ID}_{nombre}.html
```

## Nota

Los archivos se generan automáticamente cuando se publica un team desde `create_team.html`. El navegador descargará el archivo automáticamente, y deberás moverlo manualmente a esta carpeta para que la URL funcione correctamente.
