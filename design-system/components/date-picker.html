Date Picker Component

Componente de selección de fecha con calendario interactivo. Permite navegar entre meses sin cerrar el picker. Al hacer clic en una fecha, se selecciona automáticamente y se cierra. Utiliza todos los tokens de diseño del sistema.

Date Picker (Funcional)

Date picker interactivo con funcionalidad completa. Haz clic en el botón para abrir el calendario.

JavaScript

El date picker requiere JavaScript para inicializar. Usa la función initDatePicker(pickerId, buttonId, buttonTextId). 

initDatePicker('datePicker', 'datePickerButton', 'datePickerButtonText');
