Sticky Buttons

Componente de botones pegados a la parte inferior de la pantalla. Típicamente usado para acciones principales en formularios o pantallas de edición.

Nota: Este componente usa position: sticky y se mantendrá fijo en la parte inferior cuando se implemente en un layout con scroll. El contenedor padre debe tener altura suficiente para que el efecto sticky funcione correctamente.

Ejemplo

Código de implementación: 
<!-- El contenedor padre debe tener altura suficiente para que sticky funcione -->
<div style="min-height: 100vh;">
  <!-- Contenido de la página -->
  
  <!-- Sticky buttons al final -->
  <div class="dsu-sticky-buttons">
    <button class="dsu-button dsu-button--secondary dsu-button--medium dsu-sticky-buttons__button">
      Save draft
    </button>
    <button class="dsu-button dsu-button--primary dsu-button--medium dsu-sticky-buttons__button">
      Publish
    </button>
  </div>
</div>
