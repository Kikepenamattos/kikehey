Navigation Component

Sistema de navegación sidebar con todas sus variantes, estados e interacciones. Basado en el diseño exacto de Figma Components. Incluye logo, botones de navegación, dropdown de proyectos, y footer funcional. El footer (Dark mode y Logout) se mantiene siempre en la parte inferior del sidebar, ajustándose automáticamente a la altura del contenedor. Las secciones de Teams y Projects pueden expandirse simultáneamente sin interferir entre sí.

Layout Behavior

El sidebar utiliza flexbox para mantener el footer (Dark mode y Logout) siempre en la parte inferior, independientemente del contenido. El área de navegación principal puede hacer scroll si es necesario, mientras que el footer permanece fijo en la parte inferior del contenedor.

  • Sidebar tiene height: 100vh para ocupar toda la altura del viewport
  • Navigation Wrapper usa flex: 1 para ocupar el espacio disponible
  • Navigation Main tiene overflow-y: auto para permitir scroll cuando hay mucho contenido
  • Footer tiene margin-top: auto y flex-shrink: 0 para mantenerse siempre en la parte inferior
  • Las secciones de Teams y Projects funcionan de forma independiente y pueden expandirse simultáneamente
