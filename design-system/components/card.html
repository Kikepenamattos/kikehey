Profile Card Placeholder

Tarjeta placeholder para agregar nuevos miembros al equipo. Toda la card tiene zona activa (clickeable) para facilitar la interacción. Al hacer clic en cualquier parte de la card, se activa la funcionalidad de agregar un nuevo miembro.

Profile Card Placeholder - Estado Default
Name
Job position
email
Contact
Código HTML: 
<div class="dsu-profile-card-placeholder" id="addMemberCard">
    <div class="dsu-profile-card-placeholder__image">
        <div class="dsu-profile-card-placeholder__edit-icon">
            <img src="images/plus.svg" alt="Add member">
        </div>
    </div>
    <div class="dsu-profile-card-placeholder__content">
        <div class="dsu-profile-card-placeholder__name-job">
            <div class="dsu-profile-card-placeholder__name">Name</div>
            <div class="dsu-profile-card-placeholder__job">Job position</div>
        </div>
        <div class="dsu-profile-card-placeholder__contact">
            <div class="dsu-profile-card-placeholder__contact-item">
                <img src="images/mail.svg" alt="Email" class="dsu-profile-card-placeholder__contact-icon">
                <span class="dsu-profile-card-placeholder__contact-text">email</span>
            </div>
            <div class="dsu-profile-card-placeholder__contact-item">
                <img src="images/whatsapp.svg" alt="Contact" class="dsu-profile-card-placeholder__contact-icon">
                <span class="dsu-profile-card-placeholder__contact-text">Contact</span>
            </div>
        </div>
    </div>
</div>

<script>
    // Hacer toda la card clickeable
    const placeholderCard = document.getElementById('addMemberCard');
    placeholderCard.addEventListener('click', function() {
        // Abrir modal o funcionalidad para agregar miembro
        openAddMemberModal();
    });
</script>
