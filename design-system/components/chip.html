Chip

Componente chip para mostrar etiquetas o tags. Diseñado específicamente para asociar proyectos, pero puede utilizarse en cualquier contexto donde se necesite mostrar etiquetas removibles. Basado en el diseño exacto de Figma con fondo gris claro (#efefef), bordes redondeados completos (50px) y tipografía Lato Regular de 13px.

Default

Chip básico con texto y botón de cierre para eliminar el chip.

Especificaciones de Diseño

El componente Chip está diseñado exactamente según las especificaciones de Figma:

  • Background: #efefef (status-disabled)
  • Border: none
  • Border Radius: 50px (completamente redondeado)
  • Padding: 8px vertical, 16px horizontal
  • Gap: 10px entre elementos internos
  • Font Family: Lato (var(--font-family-secondary))
  • Font Size: 13px
  • Font Weight: Regular (var(--font-weight-regular))
  • Text Color: #0a243f (var(--color-text-primary))
  • Text Align: center
  • Hover State: background-color cambia a #e0e0e0

Uso con Input

Ejemplo completo de uso del componente Chip con un input para agregar proyectos asociados. Al presionar Enter en el input, se crea un nuevo chip.

Preview Interactivo
<input type="text" id="associatedProjects" placeholder="Type the projects name"> <div class="projects-chips-container" id="projectsChipsContainer"> <!-- Chips will be dynamically added here --> </div> <script> const input = document.getElementById('associatedProjects'); const container = document.getElementById('projectsChipsContainer'); input.addEventListener('keydown', function(e) { if (e.key === 'Enter') { e.preventDefault(); const value = input.value.trim(); if (value) { // Crear y agregar chip const chip = createChip(value); container.appendChild(chip); input.value = ''; } } }); </script>

Implementación JavaScript

Código JavaScript completo para manejar la creación y eliminación de chips dinámicamente.

// Función para crear un chip function createChip(text) { const chip = document.createElement('div'); chip.className = 'project-chip'; chip.setAttribute('data-project', text.trim()); const chipText = document.createElement('span'); chipText.className = 'project-chip__text'; chipText.textContent = text.trim(); const closeBtn = document.createElement('button'); closeBtn.className = 'project-chip__close'; closeBtn.setAttribute('aria-label', 'Remove project'); closeBtn.innerHTML = '<svg class="project-chip__close-icon" viewBox="0 0 12 12" fill="none" xmlns="http://www.w3.org/2000/svg"><path d="M9 3L3 9M3 3L9 9" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"/></svg>'; closeBtn.addEventListener('click', function(e) { e.stopPropagation(); chip.remove(); saveProjects(); // Guardar estado }); chip.appendChild(chipText); chip.appendChild(closeBtn); return chip; } // Manejar Enter key input.addEventListener('keydown', function(e) { if (e.key === 'Enter') { e.preventDefault(); const value = input.value.trim(); if (!value) return; // Verificar si ya existe (prevenir duplicados) const existingChips = Array.from(container.querySelectorAll('.project-chip')); const exists = existingChips.some(chip => chip.getAttribute('data-project').toLowerCase() === value.toLowerCase() ); if (!exists) { const chip = createChip(value); container.appendChild(chip); saveProjects(); } input.value = ''; } });
